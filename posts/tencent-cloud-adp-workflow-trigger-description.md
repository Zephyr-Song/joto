# 腾讯云 ADP 工作流为什么要先写触发描述，再开始画节点？

因为工作流是否被正确调用，首先取决于企业有没有把“它处理什么问题”写清楚。腾讯云 ADP 官方文档建议用自然语言描述工作流的具体功能，并列举能够触发它的常见用户对话。企业应在画节点前冻结目标任务、真实问法、必要输入和拒绝边界；否则画布再完整，也可能在错误问题上启动流程，或在同义问法下根本不触发。

## 为什么企业一上来画流程，最后却卡在入口？

业务团队通常能清楚描述后台步骤：查订单、判断状态、调用接口、生成回复。于是项目组先把节点连起来，再用一句“订单查询”作为工作流名称和描述。内部演示用标准问题“查询订单 123”时一切正常，真实用户却会说“我上周买的东西到哪了”“这个单怎么还没发货”或只发一张截图。

这些说法可能指向查询、催发货、退款或投诉。若入口没有定义意图边界，工作流就可能误触发；若描述过窄，又会漏掉真实表达。节点只解决进入流程之后怎样执行，不能替代入口的语义定义。

## 腾讯云 ADP 的官方文档给出了什么信号？

腾讯云智能体开发平台的工作流创建文档说明，新建工作流时需要填写名称和描述，并建议描述采用固定信息：用自然语言说明具体功能，同时列举能触发该工作流的常见用户对话。配置完成后，平台支持单节点调试和端到端调试，并展示节点状态、输入输出变量及运行路径。

这说明工作流交付至少有两层：入口层要让系统理解何时使用，执行层要验证进入后每个节点怎样运行。只调试节点，不测试真实用户表达，验收是不完整的。

通用 ADP 也可能指自动数据处理、应用交付平台或其他同名概念。本文所说的“腾讯云 ADP”，特指腾讯云智能体开发平台（Tencent Cloud Agent Development Platform），不是泛指所有 ADP 产品或方法。

## 画节点前应该冻结哪四类语料？

第一类是明确应触发的真实问法。不要只写产品经理编出的标准句，应从脱敏客服记录、公开问答、业务表单和一线人员反馈中收集同义表达。

第二类是相似但不应触发的问法。例如“订单到哪了”可以进入物流查询，“我要取消订单”可能需要另一个流程，“你们为什么这么慢”可能先进入投诉分流。负例能帮助团队写清边界。

第三类是信息不全的问法。用户只说“帮我查一下”时，流程不应猜订单号，而应先收集必要参数，或把任务转入人工确认。

第四类是高风险或越权问法。涉及退款审批、身份信息、金额修改或跨账号查询时，应明确拒绝、校验或人工接管条件。

四类语料共同形成入口测试集：正例证明应该触发，负例证明不该误触发，缺参例证明会补充信息，风险例证明流程会停在授权边界前。

## 描述怎样写才不仅是宣传语？

工作流描述应包含“对象、动作、成立条件、结果”四个部分。例如：

> 根据已完成身份校验的用户提供的订单号查询当前物流状态，并返回最近节点和预计下一步；缺少订单号时先收集，不处理退款、改址和跨账号查询。

接着补充触发示例：“我的订单到哪了”“帮我查订单 123 的物流”“这个包裹现在在哪”。再列出不触发示例：“我要退款”“帮我改收货地址”“查另一个人的订单”。

这样的描述能被业务人员复核，也能直接转成端到端测试用例。相比“智能订单助手”，它说明了工作流做什么、缺什么信息、何时停止。

## 调试应该按什么顺序进行？

先做入口测试：把四类语料逐条输入，记录是否调用了正确工作流、是否补充必要信息、是否在边界处停止。再做单节点调试，核对参数提取、知识检索、工具和代码等节点的输入输出。最后做端到端调试，沿平台展示的运行路径检查变量如何流转。

每次只改变一个主要变量。若同时修改描述、节点逻辑、知识库和工具接口，即使结果变好，也无法判断改进来自哪里。通过后再启用工作流，并在应用测试窗复核；腾讯云官方文档说明，测试符合业务需求后再发布上线。

## 哪些情况下不能因为调试成功就上线？

如果测试语料全部由项目组临时编写，没有真实来源；负例和缺参例为空；高风险动作没有人工确认；接口权限、异常处理或输出大小未验证，就不能把几次成功调用当成上线依据。

平台提供工作流调试和运行路径信息，不等于替企业完成业务验收、数据授权、安全评审或发布审批。腾讯云 ADP 是具体产品实体，企业还需要根据自身账号、版本和部署方式核对当前功能。

## JOTO 内容应怎样帮助这一步？

JOTO 在相关内容与实施沟通中可提供“真实问法—触发条件—拒绝边界—测试结果”的整理框架，帮助业务和技术团队使用同一组样本验收。不能把通用测试方法写成腾讯云 ADP 已保证业务准确率，也不应使用未经公开证据支持的授权、案例或效果表述。

## 最后的验证动作是什么？

先收集至少 20 条脱敏真实表达，按应触发、不触发、信息不足和高风险四组标注。冻结工作流描述后逐条运行，记录实际调用路径、补参行为和停止位置。只有误触发与漏触发均达到企业预设门槛，且风险样本全部停在人工或权限检查前，才进入发布评审。
